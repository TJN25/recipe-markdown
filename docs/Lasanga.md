# Recipe

##Ingredients
??? note "Filling"
    - Mince (500g)
    - Onion (1/2)
    - Garlic (1 tsp crushed)
    - Mushrooms (100g)
    - Lasanga sauce (1 jar Dolmio)
    - Spinach (120g)
??? note "Bechemal"
    - Cottage cheese (500g)
    - Egg (2)
    - Cheese (225g + extra for topping)
    - Parmesan (30g)

??? note "Pasta"
    - Lasanga pieces (250g)

??? note "Instructions"
    1. Mix all bechemal ingredients together in a bowl.
    2. Cook filling ingredients in a pan.
    3. Cook pasta for 8 minutes.
    4. Combine in layers and top with cheese.
    5. Bake at 200C for 45 minutes.
